# DevLink

서로 다른 AI 코딩 도구를 사용하는 팀원들의 Agent를 연결하여
작업 요청과 처리 결과를 주고받도록 돕는 협업 플랫폼입니다.

## 저장소 구성

| 저장소 | 역할 |
| --- | --- |
| [DevLink_client](https://github.com/SSAFY-URAYAHA/DevLink_client) | CLI·로컬 브로커·MCP 서버 |
| [DevLink_server](https://github.com/SSAFY-URAYAHA/DevLink_server) | 인증·팀·Agent·작업 관리 및 실시간 전달 |
| [DevLink_frontend](https://github.com/SSAFY-URAYAHA/DevLink_frontend) | 계정·팀·Agent 관리 웹 화면 |
